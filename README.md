## 🚀 Key Portal Features

- **Smart Multi-Token Search (Ctrl + K):**
  - Type words in any order (e.g. `Aadhaar Phone Update`) to immediately highlight and filter services across all categories.
- **Personal Pinned Shortcuts:**
  - Star any portal to keep it saved to your personal top shelf across browser sessions via `localStorage`.
- **100% Direct Sovereign Links:**
  - Standardized with `rel="noopener"` for security while maintaining browser referrer integrity for government route guards.
- **Offline Document Checklist Reference:**
  - Quick modal view detailing required documents, fees, and verification rules for every service.

## 🛠️ Technology Stack

- **Frontend:** React 18
- **Build Tool:** Vite 5 (Relative base paths `./` for universal hosting)
- **Styling:** Tailwind CSS (Dark/Slate personal dashboard theme)
- **Icons:** Lucide React (Tree-shaken, ultra-lightweight)
- **Deployment:** Vercel + GitHub Pages (Automated GitHub Actions workflow)

## 🏃 Local Development

```powershell
# Clone the repository
git clone https://github.com/KornipatiAkash-1969/chandu-online-services.git

# Navigate into directory
cd chandu-online-services

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.
